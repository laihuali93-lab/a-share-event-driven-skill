# A股事件驱动短线研究技能（催化寻龙 + 首板挖掘）

合并后的 Grok 自定义技能，整合原 `cuohua-xunlong`（催化寻龙）与 `shouban-wajue`（首板挖掘）。

## 用途
- 连板（D池）相对强度顺位排序
- 次日首板（E池）发现与挖掘
- 有连板预期的重组并购候选
- 根据实盘结果修正模型

## 触发词
催化寻龙、连板、首板、涨停、D/E研究、重组并购、续板概率、寻龙、首板挖掘、超短首板、明天买哪只首板、首板候选

## 核心规则
- 顺位 ≠ 概率（概率未审计前不输出数字）
- 双门槛默认严格（流通市值 <100亿 且 股价 <20元）
- 缺证写「待核」，不填0不臆造
- 每次 D/E 先声明市场情绪状态（冰点/正常/过热）
- 竞价是硬过滤，可一票否决

- `SKILL.md` — 主技能文件（含首板挖掘打分表与流程）
